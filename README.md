# 🎂 Interactive Birthday Gift — A Cinematic Film in Four Acts

# 🎂 Regalo interactivo de cumpleaños — Una película en cuatro actos

> Creado por **Vivek Kumar**  
> Una tarjeta y película de cumpleaños interactiva para la web, hecha con JavaScript, Canvas 2D, animaciones GSAP y una banda sonora sintetizada con Web Audio API.

---

## ✨ Características

- 🏹 **Acto 1: Arco y flecha interactivos** — Tira de la cuerda del arco y suéltala para lanzar una flecha hacia la rosa.
- 🌹 **Acto 2: Impacto y oleada de rosas** — El impacto activa partículas de rosas, un efecto de retroceso y una expansión de color que cubre la pantalla.
- 🎬 **Acto 3: Un deseo en movimiento** — Una presentación cinematográfica con animaciones tipográficas que revela el mensaje de cumpleaños.
- 🌸 **Acto 4: Árbol de rosas y lluvia de pétalos** — Un árbol dibujado en Canvas 2D despliega una copa redondeada de rosas, pétalos que caen y destellos.
- 🎵 **Música con Web Audio** — Melodía sintetizada de cumpleaños y efectos de sonido para tensar la cuerda, lanzar la flecha e impactar la rosa, con control de sonido.
- ✨ **Firma del autor** — Una marca discreta con el crédito de Vivek Kumar.
- 📱 **Diseño adaptable** — Funciona en teléfonos, tabletas y computadoras.

---

## 🛠️ Tecnologías

- **HTML5 y CSS3**, con estilos propios, colores HSL y tipografía moderna
- **JavaScript (ES6+)** y **GSAP 3** para coordinar la secuencia y las animaciones
- **Canvas 2D de HTML5** para dibujar el árbol, los pétalos y los rayos de luz
- **Web Audio API** para sintetizar la música y los efectos de sonido
- **Vite** para compilar el proyecto y desplegarlo con GitHub Actions

## 🚀 Inicio rápido

1. **Clona el repositorio:**

   ```bash
   git clone https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
   cd "Interactive Birthday Gift"
   ```

2. **Instala las dependencias:**

   ```bash
   npm install
   ```

3. **Inicia el servidor de desarrollo:**

   ```bash
   npm run dev
   ```

4. **Genera la versión de producción:**
   ```bash
   npm run build
   ```
