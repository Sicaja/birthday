# 🎂 Interactive Birthday Gift — A Cinematic Film in Four Acts

> Created & Owned by **Vivek Kumar**  
> An interactive, web-based birthday card and film built with Vanilla JavaScript, HTML5 Canvas 2D, GSAP animations, and custom Web Audio API soundtrack.

---

## ✨ Features

- 🏹 **Act 1: Interactive Bow & Arrow Rig** — Draw the Cupid recurve bow string and release to shoot an arrow directly at the beating target heart.
- 💖 **Act 2: Physics-Based Strike & Rose Flood** — Arrow impact triggers heart particle bursts, recoil physics, and a full-screen rose color expansion.
- 🎬 **Act 3: Kinetic Typography Wish** — Letterboxed cinema presentation with 3D hinged typography animations revealing a birthday message.
- 🌸 **Act 4: Procedural Heart Tree & Petal Rain** — Dynamic 2D canvas tree growing and blooming with hundreds of soft heart blossom petals and drifting sparkles.
- 🎵 **Built-in Web Audio Music Box** — Custom synthesized *Happy Birthday* chime melody and sound effects (string pull, arrow flight, heart strike) with an interactive sound toggle.
- ✨ **Custom Owner Watermark** — Subtle top-left glassmorphic owner signature (`Crafted with ♥ by Vivek Kumar`).
- 📱 **Fully Responsive** — Works smoothly across all mobile devices, tablets, and desktop screen sizes.

---

## 🛠️ Built With

- **HTML5 & CSS3** (Vanilla CSS with glassmorphic styling, HSL color system, and modern typography)
- **JavaScript (ES6+)** with **GSAP 3** for timeline orchestration and kinetic physics
- **HTML5 Canvas 2D API** for procedural tree branching, petal particle systems, and god-rays
- **Web Audio API** for zero-latency synthesized music box soundtrack & sound effects
- **Vite** for fast bundling and GitHub Actions deployment

## 🚀 Quick Start (Local Development)

1. **Clone the repository:**
   ```bash
   git clone https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
   cd "Interactive Birthday Gift"
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
